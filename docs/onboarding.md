# Как подключить настоящий салон примерно за час

Этот документ — пошаговый сценарий: от заполненной анкеты клиента до живого
чата, где Майя отвечает ценами, мастерами и правилами именно этого салона.

Один сервер держит сколько угодно салонов сразу. Салоны не видят друг друга:
у каждого свои клиенты, записи, переписка, услуги, мастера, график и часовой
пояс. Учебный салон Luminous Core остаётся на месте и ничего не теряет.

**Сколько это занимает по частям:**

| Шаг | Время | Кто делает |
|---|---|---|
| 1. Клиент заполняет анкету | 20–30 мин | клиент |
| 2. Переносим анкету в файл | 15–20 мин | мы |
| 3. Пробный запуск и проверка | 5 мин | мы |
| 4. Загрузка и перезапуск | 2 мин | мы |
| 5. Проверка живым диалогом | 10 мин | мы |

---

## Шаг 1. Клиент заполняет анкету

Отправьте клиенту анкету: `local-previews/aibeaty-demo/salon-intake.html`
(та же анкета текстом — `salon-intake.md`).

В анкете девять разделов: о салоне, график, услуги с ценами и длительностью,
мастера, правила записи, частые вопросы, каналы, кто отвечает на эскалации,
тон Майи.

**Что важно получить обязательно** — без этого запуск не поедет:

- название салона, город, часовой пояс;
- график работы на все семь дней;
- хотя бы одна услуга: название, длительность в минутах, цена;
- хотя бы один мастер и список услуг, которые он делает;
- кому передавать диалог, когда клиент просит человека.

Остальное (парковка, оплата, подарочные сертификаты) можно добавить позже —
Майя просто не будет отвечать на эти вопросы, а передаст их владельцу.

## Шаг 2. Переносим анкету в файл

Возьмите готовый пример и правьте его — структура файла повторяет разделы
анкеты в том же порядке:

    cp docs/onboarding/example-salon.json /tmp/my-salon.json

Открыть и заполнить: [/tmp/my-salon.json](http://127.0.0.1:7777/open/tmp/my-salon.json)

Что стоит знать про поля:

- **`slug`** — короткий адрес салона латиницей, например `iris-beauty-bar`.
  Он попадёт в ссылку на чат и больше не меняется. Если не указать — сделаем
  из названия автоматически.
- **`hours`** — пишите `"10:00-20:00"` или `"выходной"`. Дни можно называть
  по-русски.
- **`services`** — `durationMinutes` это чистое время кресла в минутах.
  `price` можно писать как угодно: `65`, `"$65"`, `"от $110"` — Майя
  процитирует вашу формулировку слово в слово.
- **`keywords`** — как клиенты называют услугу своими словами («гель-лак»,
  «нарастить ногти»). Именно по ним Майя узнаёт услугу в живой переписке.
  Чем больше, тем лучше.
- **`staff[].services`** — названия услуг должны совпадать с разделом услуг
  **буква в букву**. Если не совпадут, импорт остановится и прямо скажет, где.
- **`staff[].aliases`** — уменьшительные и латиница («Ира», «Irina»), чтобы
  Майя узнала мастера, как бы клиент его ни написал.
- **`policies`** и **`faq`** — Майя цитирует эти ответы дословно. Пишите так,
  как сказали бы сами.

## Шаг 3. Пробный запуск

    node scripts/onboard-salon.mjs /tmp/my-salon.json --dry-run

В базу при этом **ничего не записывается**. На экран выведется то, что
получится: график по дням, все услуги с ценами и длительностью, мастера с их
услугами и рабочими днями, и полный список ответов, которые Майя будет давать.

**Прочитайте этот вывод вместе с анкетой клиента.** Здесь ловятся опечатки в
ценах и перепутанные длительности — потом это будет видно уже клиентам.

Если в анкете чего-то не хватает, скрипт напишет об этом по-русски и ничего не
изменит. Например:

    • Мастер Анна умеет услугу «балаяж», но такой услуги в списке нет.
      Добавьте её в раздел 3 или исправьте название — оно должно совпадать
      буква в букву.
    • Не понял часы работы для дня «вторник»: «9 до 19».
      Пишите так: «09:00-19:00», а для выходного — «выходной».

Исправьте файл и запустите пробный запуск снова. Так можно сколько угодно раз.

## Шаг 4. Загрузка на сервер

Скопируйте файл анкеты на сервер и запустите импорт там:

    scp /tmp/my-salon.json root@46.175.145.180:/opt/aibeaty/
    ssh root@46.175.145.180
    cd /opt/aibeaty
    sudo -u aibeaty env $(grep -v '^#' .env | xargs) node scripts/onboard-salon.mjs my-salon.json --dry-run
    sudo -u aibeaty env $(grep -v '^#' .env | xargs) node scripts/onboard-salon.mjs my-salon.json
    systemctl restart aibeaty aibeaty-tg

Скрипт напечатает, что создал, и подскажет ссылку на чат этого салона.

**Повторный запуск с тем же `slug` не создаёт второй салон** — он обновляет
существующий. Услуги и мастера сопоставляются по названию: цена поменялась —
поменяется на месте; услугу убрали из анкеты — уйдёт и из системы; записи
клиентов при этом не трогаются. Поэтому «клиент прислал уточнённый прайс» —
это просто ещё один запуск той же команды.

Проверить список салонов на сервере:

    cd /opt/aibeaty
    sudo -u aibeaty env $(grep -v '^#' .env | xargs) node scripts/list-salons.mjs

Команда печатает первой строкой файл базы. **Смотрите на неё.** Без окружения
сервера (`env $(grep ...)`) скрипт откроет локальный файл репозитория и покажет
пустой или устаревший список — он предупредит об этом отдельной строкой.

## Шаг 5. Проверка живым диалогом

Ссылка на чат нового салона — это обычный адрес демо плюс `?salon=<slug>`:

    https://aibeaty.remolda.com/screens/chat.html?salon=iris-beauty-bar

Откройте её и проведите короткий диалог. Проверьте пять вещей:

1. **Цена.** Спросите про услугу — Майя должна назвать цену из анкеты этого
   салона, слово в слово.
2. **Мастер.** Назовите мастера уменьшительным именем — Майя должна его узнать.
   Назовите несуществующее имя — должна честно сказать, что такого мастера нет.
3. **График.** Спросите про день, который у салона выходной — Майя должна
   отказать и предложить ближайший рабочий день.
4. **Запись.** Доведите до записи. Майя обязана сначала зачитать сверку и
   дождаться «да», и только потом сказать «вы записаны».
5. **Человек.** Напишите «позовите человека» — диалог должен уйти сотруднику.

Запись после диалога должна появиться в расписании этого салона:

    https://aibeaty.remolda.com/screens/stylist-schedule-luminous-core.html?salon=iris-beauty-bar

(адрес страницы остался прежним — меняется только `?salon=`)

## Шаг 6. Поставить чат на сайт клиента

Две строки в шаблон сайта, перед `</body>`:

```html
<script>
  window.AIBEATY_API_BASE = "https://aibeaty.remolda.com";
  window.AIBEATY_SALON = "iris-beauty-bar";
</script>
<script src="https://aibeaty.remolda.com/assistant-widget.js" defer></script>
```

`AIBEATY_SALON` — это тот же `slug`. Без него виджет будет говорить от имени
учебного салона, так что не забудьте эту строку.

## Telegram-бот для салона

Один бот обслуживает один салон. Заведите бота через @BotFather, положите токен
в `.env` сервера и укажите салон:

    TELEGRAM_BOT_TOKEN=<токен от BotFather>
    TELEGRAM_SALON_SLUG=iris-beauty-bar

Затем `systemctl restart aibeaty-tg`. В логе при старте видно, за какой салон
бот отвечает. Если для второго салона нужен свой бот — это отдельная копия
сервиса со своим токеном и своим `TELEGRAM_SALON_SLUG`.

## Что где лежит

| Что | Где |
|---|---|
| Анкета для клиента | `local-previews/aibeaty-demo/salon-intake.html` |
| Пример заполненного файла | `docs/onboarding/example-salon.json` |
| Скрипт импорта | `scripts/onboard-salon.mjs` |
| Данные всех салонов | `/var/lib/aibeaty/platform.db` на сервере |
| Список салонов | `scripts/list-salons.mjs` |

Учебный салон Luminous Core — единственный, чьи тексты живут в файле
`apps/platform/data/salon-faq.json` и перечитываются при каждом перезапуске.
Все салоны, заведённые через анкету, хранятся в базе, и этот файл их не
касается.

## Если что-то пошло не так

**«Unknown salon» в ответе сервера.** Салона с таким `slug` на сервере нет.
Посмотрите список командой из шага 4. Опечатка в `?salon=` — самая частая
причина.

**Майя называет чужие цены.** Значит, в ссылке нет `?salon=` (или на сайте нет
строки `window.AIBEATY_SALON`) — и она отвечает от имени учебного салона.

**Майя не узнаёт услугу.** Добавьте в `keywords` этой услуги слова, которыми
клиент её назвал, и запустите импорт ещё раз.

**Сбросить учебный салон, не тронув остальные:**

    node apps/platform/server.js --reset-state

Сбросить конкретный салон:

    node apps/platform/server.js --reset-state --salon=iris-beauty-bar
